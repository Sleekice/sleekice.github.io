🧭 Project 02
● Live
SOIR — A* Pathfinding Visualizer
Python implementation of the A* algorithm with a real-time interactive Pygame visualizer, color-coded node states, and dynamic obstacle placement.

Designed and implemented the A* pathfinding algorithm from scratch in Python, using heuristic-based priority queues (heapq) to compute the optimal path between two coordinate points.

Features real-time visualization with color-coded node states (open, closed, path, wall, start, end), dynamic obstacle placement, and step-by-step traversal display. Applied graph theory concepts from HPC research (network topology, algorithmic efficiency) to build a clean, educational tool.
